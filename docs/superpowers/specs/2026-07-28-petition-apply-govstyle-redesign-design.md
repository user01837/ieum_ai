# 민원 접수 공개 폼(/apply) 국민신문고 스타일 재구성 설계

- 작성일: 2026-07-28
- 관련 저장소: `ieum_frontend`
- 관련 기존 기능: [민원 접수 공개 폼 설계](./2026-07-28-petition-public-apply-form-design.md) — 이 문서에서 만든 `/apply` 페이지(`src/pages/Apply/Apply.jsx`, `Apply.module.css`)의 **UI만** 재구성한다. API 호출·검증·라우팅 로직은 그대로 둔다.

## 배경 및 목적

기존 `/apply` 페이지는 `Login.jsx`와 동일한 네이비 그라디언트 배경 + 흰 카드 스타일로 만들었으나, 팀 논의 결과 "공공이음 내부 시스템 느낌"이 아니라 실제 국민신문고 민원 접수 페이지에 가까운 느낌으로 바꾸기로 했다. 사용자가 제공한 실제 국민신문고 페이지(mois.go.kr) 스크린샷과 텍스트를 참고해 재구성한다.

**필드는 그대로 제목·내용 두 개만 유지한다 — 첨부파일 업로드는 이번에도 범위 밖.**

## 디자인

**전체 톤**: 로고·브랜딩 없이 흰 배경 + 무채색(회색/검정 계열) 텍스트, 카드 그림자나 그라디언트 없는 평범한 관공서 문서 느낌. 국민신문고처럼 페이지 상단부터 바로 안내문구·폼이 시작된다.

**입력 화면 구성 (위에서 아래 순서)**:
1. 안내 문구 6줄(그대로 사용, 아래 "콘텐츠" 절 참고)
2. "민원내용" 섹션 헤더
3. 유의사항 안내 문구 4개(그대로 사용, 로그인 유지시간 문구만 우리 서비스에 안 맞아 제외)
4. "민원 제목" 라벨 + `필수입력` 배지, 텍스트 입력(`maxLength=200`), 우측 하단 `(글자수/200)` 카운터
5. "민원 내용" 라벨 + `필수입력` 배지, 텍스트영역(`maxLength=40000`), 우측 하단 `(글자수/40000)` 카운터
6. 인라인 에러(빈 값 제출 시) — 기존 로직 그대로, 스타일만 새 톤에 맞춤
7. "접수하기" 버튼 — 무채색 계열(진한 회색/검정 배경)

**완료 화면**: 같은 흰 배경 + 무채색 톤. 카드/그라디언트 없이 테두리 박스 안에 "민원이 정상적으로 접수되었습니다" + 접수번호·배정 부서·처리예정일 표(지금의 `resultRow` 구조 유지, 색상만 무채색으로).

### 콘텐츠 (그대로 사용)

**상단 안내 6줄**:
```
제목과 내용은 접수 후 수정, 삭제가 불가능하므로 다시 확인하시고 신청해 주시기 바랍니다.
규제 관련 민원의 경우 규제신문고로 이관될 수 있습니다.
신고성 민원의 경우 청렴포털시스템으로 이관될 수 있습니다.
허위신고 등은 명예훼손, 무고죄 등으로 처벌될 수 있습니다.
민원 내용에 따라 여러 부처에서 처리될 수 있으니, 민감한 내용이 포함되어 있을 경우 기관별로 해당내용을 제출해주시기 바랍니다.
공무원에 대한 폭언, 욕설 등은 관련 법령(형법, 경범죄처벌법)에 따라 법적조치를 받을 수 있습니다.
```

**유의사항 4개** (마지막 문구는 로그인 유지시간 부분 제외):
```
※ 민원신청을 유도한 후 금융 정보(계좌, 카드, 비밀번호 등)를 요구하는 전화사기(보이스피싱)에 주의하시기 바랍니다.
※ 고소장 등 법정서식이 필요한 신청은 해당 기관에 사전 문의하시기 바랍니다.
※ 현금영수증 미발급·발급거부, 신용카드 결제거부, 탈세제보신고는 국세청 홈(손)택스로 접속> 상담/제보(클릭)를 이용하여주시기 바랍니다.
※ 민원 내용을 자세히 작성해주시면 원활한 민원 처리에 도움이 됩니다.
```

## 컴포넌트

`ieum_frontend`만 수정한다.

### `src/pages/Apply/Apply.jsx`
- 로고 import(`logo`)와 `brandrow` 마크업 삭제
- 안내 문구 6줄 + 유의사항 4줄을 정적 텍스트로 추가
- 제목/내용 입력에 `maxLength` 속성 추가(200 / 40000), 각 필드 아래에 글자수 카운터(`{title.length}/200`, `{content.length}/40000`) 표시
- 라벨 옆에 `필수입력` 배지(작은 태그) 추가
- 완료 화면(`result` 분기)의 마크업 구조는 유지하되 클래스명/톤만 새 스타일에 맞춰 조정
- API 호출(`submitExternalPetition`), 검증 로직(빈 값 체크), mutation 훅 사용 방식은 전혀 안 바꿈

### `src/pages/Apply/Apply.module.css`
- 기존 네이비 그라디언트/카드/그림자 스타일 전면 교체
- 흰 배경(`background: #fff` 또는 `var(--bg)`), 회색 계열 텍스트(`var(--ink)`, `var(--ink-soft)`), 테두리는 `var(--line-strong)` 재사용(색상 자체는 기존 CSS 변수 그대로 — 다만 배경의 그라디언트/카드 그림자는 제거)
- 버튼은 진한 회색/검정 배경(`#333` 또는 `var(--ink)`)으로, 기존 `var(--navy)` 파란 계열 대신 무채색 사용
- 안내문구 영역은 작은 회색 텍스트, 유의사항은 `※` 기호 포함 리스트 스타일

## 테스트

기존과 동일하게 자동화 테스트 없이 진행:
- `npm run dev`로 `/apply` 접속해 육안으로 국민신문고 스타일과 비슷한지 확인
- 글자수 카운터가 실제 입력에 따라 갱신되는지, `maxLength` 초과 입력이 막히는지 확인
- 기존 기능(빈 값 에러, 정상 제출→완료 화면, 완료 화면의 접수번호/부서/처리예정일 표시, 새 민원 접수하기 버튼)이 스타일 변경 후에도 그대로 동작하는지 확인 — 로직은 안 건드렸으므로 회귀 없어야 함
